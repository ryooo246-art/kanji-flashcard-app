# かんじカード ✨  (v2.0)

小学生むけ・漢字よみあげフラッシュカードアプリ（1年生分・80字）

対象の漢字が使われた単語（例:「一」→「一つ」）が表示され、声に出して読むと
Gemini APIが読み方をチェックしてくれます。正解すると派手な演出とほめ言葉で
やる気を盛り上げます。

## 特徴

- 学年ごとにチェックを入れて出題範囲を選べる（現在は1〜3年生・440字と、ひらがな・カタカナが収録済み。
  4〜6年生は「じゅんびちゅう」表示で、CSVを追加すればそのまま使えます）
- ひらがな・カタカナは1文字ずつ出題される練習モード
- 同じ漢字の別の単語が続けて出題される（例:「一つ」→「一まい」→「一年生」）
- ミントグリーン基調のかわいいデザイン、成長する植物マスコット付き
- 正解時の演出は4パターン（紙吹雪・キラキラ・花びら・リボン）からランダム表示
- 正解すると2秒間、読み方をひらがなで表示してから次の問題へ進む
- 10問ごとに「つづける？」の確認が入り、そこまでの正答率を確認しながら遊べる
- 終了時に正答率を表示し、正答率に応じたほめ言葉が出る
- 不正解時はブザー音なし。やさしい声かけとヒント表示のみ
- マイクは音量を検知して自動で録音を止めるので、タップは開始の1回だけでOK
- **v2.0** カタカナは「ア〜サ行／タ〜ハ行／マ〜ン」のチェックボックスで出題範囲を選べる
  （4択の不正解候補も、チェックした範囲の中から選ばれる）
- **v2.0** 漢字の答え方を、ラジオボタンで「えらぶ(4択)」「こえで こたえる(音声認識)」から選べる
  （初期値は4択。ひらがな・カタカナは常に「きいて えらぶ」）
- **v2.0** 4択の選択肢は、実在する他の単語の読みから「正解に似たもの」を自動で選ぶ。
  ヒントを押すと、不正解の選択肢が2つ消えて2択になる

## セットアップ

### 1. ローカルサーバーで起動する

CSV読み込みとマイク機能（getUserMedia）はブラウザの制約上、
`file://` で直接開くと動かないことがあるため、簡易サーバー経由で開いてください。

```bash
cd kanji-flashcard-app
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。

### 2. Gemini APIキーを設定する

1. https://aistudio.google.com/apikey にアクセスして「Create API key」でキーを発行
2. アプリを開いたら、画面上部の「Gemini APIキー設定」欄にキーを貼り付けて「保存」をタップ
3. 必要なら「使えるモデルを取得」を押すと、そのキーで実際に使えるモデル一覧を取得し、
   一番よさそうなモデルを自動で選びます

入力したキーはこの端末のブラウザ（`localStorage`）にのみ保存され、外部には送信されません。
コードやファイルにキーを書き込む必要はなく、GitHubにpushしてもキーが公開される心配はありません
（英文の発音チェックアプリと同じ方式です）。

指定したモデルが後日Google側で廃止・利用制限されても、429（制限超過）や404（廃止）を検知すると
自動的に他のモデルへ切り替えて再試行します。

### 3. 使い方

1. 学年にチェック（今は1年生のみ）→「スタート！」
2. カードに出た単語をマイクボタンをタップして読み上げる
3. 正解すると派手な演出＋ほめ言葉、続けて同じ漢字の別の単語が出る
4. 「💡ヒント」で読み方をひらがな表示、「➡️つぎへ」でスキップも可能

## 読み方の判定方式

Gemini自身に「正解/不正解」を判定させると甘くなりがちなため、Geminiには
「何と聞こえたか」をひらがなで書き起こしてもらうだけにし、正誤判定はアプリ側の
コードで厳密に文字列比較しています。

- 3文字以下の短い読み方は完全一致のみ正解
- 4文字以上は、聞き取りの揺れ（促音の有無など）を1文字分だけ許容

## データについて (`data/*.csv`)

`grade,kanji,word,reading` の4列CSV（任意で5列目 `choices` を追加できます）です。

**4択の選択肢について（5列目 `choices`・任意）**
漢字の4択では、不正解の選択肢は他の単語の読みから自動で選ばれます。
自動で選ばれる候補がいまいちな単語だけ、5列目に「まぎらわしい読み」を `|` 区切りで
書くと、それが優先して使われます（3つ未満なら残りは自動で補います）。

```
1,生,生きる,いきる,おきる|できる|あきる
```

同じ表記で別の読みを持つ単語（例: 二人＝ふたり／ににん）の読みは、不正解の候補に
使われないようにしています。`grade`列には学年の数字のほか、
`hiragana`/`katakana`（1文字ずつ練習するモード）も入れられます。

- `data/grade1.csv`〜`grade3.csv`：1〜3年生の教育漢字（各字2〜3個の例単語、または1〜2個）
- `data/hiragana.csv`／`data/katakana.csv`：かな46字を1文字ずつ練習

これらはClaudeが下書きとして作成したものなので、読み方や単語選びに違和感があれば
自由に編集・追加してください。

4〜6年生を追加する場合は、同じ形式で `data/grade4.csv` などを作り、
`app.js` の `CATEGORIES` にある該当学年の `file: null` を `file: 'data/grade4.csv'` に
書き換えるだけで、自動的に選択できるようになります
（`state.wordsByGrade` にデータが入っていれば自動的に有効化されます）。

## GitHubで管理する

1. GitHub上で新しいリポジトリを作成する（Add a README等はチェックしないで空のまま作成）
2. このフォルダ（`kanji-flashcard-app`）で以下を実行

```bash
git init
git add .
git commit -m "初回コミット: かんじカード"
git branch -M main
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
git push -u origin main
```

APIキーはコード内に一切含まれないため、公開リポジトリにpushしても問題ありません。
そのままGitHub Pagesを有効にすれば、スマホからも常時アクセスできるようになります
（初回アクセス時にブラウザ側でAPIキーを入力するだけでOKです）。
